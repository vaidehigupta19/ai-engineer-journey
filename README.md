# AI Engineer — Learning Journey

A structured, self-directed path from programming fundamentals to production-grade AI systems. This repository documents hands-on progress across data analysis, machine learning, deep learning, NLP, and applied LLM/agent engineering — with a portfolio project anchoring each major phase.

---

## 🧠 Skills & Topics

### 1. Programming — Python
Foundation for everything that follows: writing clean, working code and reasoning through logic before introducing any ML/AI abstraction.
- [x] Core syntax, variables, and data types (`int`, `float`, `string`, `boolean`)
- [x] String manipulation and formatting (methods, f-strings, type conversion)
- [x] Control flow — conditionals, `for`/`while` loops
- [x] Data structures — lists, tuples, dictionaries, comprehensions
- [x] Functions — parameters, return values, default args, `*args`/`**kwargs`
- [x] Error handling — `try` / `except` / `finally`
- [x] Version control — Git & GitHub workflow (commits, pushes, repo structure)

### 2. Data Analysis
The day-to-day toolkit for exploring, cleaning, and understanding data before any modeling happens.
- [x] NumPy — array creation, indexing, vectorized operations, broadcasting
- [ ] Pandas — DataFrames, filtering, grouping, merging, cleaning, missing-value handling
- [ ] Data visualization — Matplotlib and Seaborn (distributions, correlations, categorical plots)
- [ ] Exploratory Data Analysis (EDA) — structured workflow from raw dataset to documented insights

### 3. SQL
The standard interface for working with structured data at scale — a near-universal requirement in data and ML roles.
- [ ] Querying, filtering, sorting (`SELECT`, `WHERE`, `ORDER BY`)
- [ ] Aggregations and `GROUP BY`
- [ ] Joins — inner, outer, left, right
- [ ] Subqueries, CTEs, and window functions

### 4. Statistics & Probability
The mathematical reasoning underneath every ML model — needed to interpret results, not just produce them.
- [ ] Descriptive statistics (mean, median, variance, standard deviation)
- [ ] Probability fundamentals and distributions
- [ ] Hypothesis testing and statistical significance
- [ ] Correlation and linear algebra basics (vectors, matrices)

### 5. Machine Learning
Building, evaluating, and tuning predictive models — the core discipline of applied ML.
- [ ] Supervised learning — linear/logistic regression, decision trees, random forests, gradient boosting (XGBoost, LightGBM)
- [ ] Model evaluation — classification/regression metrics, cross-validation, bias-variance tradeoff
- [ ] Feature engineering and hyperparameter tuning
- [ ] Unsupervised learning — K-Means, PCA, DBSCAN, hierarchical clustering
- [ ] Scikit-learn pipelines and model deployment fundamentals

### 6. Deep Learning & NLP
Neural network-based methods for unstructured data — images and text.
- [ ] Neural network fundamentals and backpropagation
- [ ] Convolutional Neural Networks (CNNs) and transfer learning
- [ ] Text preprocessing and vectorization
- [ ] Transformer architecture (intuition-level) and Hugging Face ecosystem

### 7. LLM & AI Engineering
Applying large language models to build real, production-oriented systems — the core of the "AI Engineer" role as distinct from traditional ML.
- [ ] LLM APIs and prompt engineering (fundamentals + practical patterns)
- [ ] Retrieval-Augmented Generation (RAG) and vector databases
- [ ] Fine-tuning fundamentals and light hands-on practice
- [ ] AI agents — tool use, planning/reasoning, state & memory, multi-agent patterns
- [ ] Model Context Protocol (MCP) and orchestration frameworks (LangChain, CrewAI)
- [ ] LLM evaluation, observability, safety/guardrails, and deployment

### 8. CS Fundamentals
Core computer science knowledge expected in technical interviews and engineering roles.
- [ ] Operating Systems
- [ ] Database Management Systems (DBMS)
- [ ] Computer Networks
- [ ] Object-Oriented Programming (OOP)

## 🎯 What completion looks like

By the end of this journey, the goal is to be able to independently take an AI product idea from raw data to a deployed, evaluated system — not just know the theory behind each piece.

Concretely, that means being able to:
- Write clean, well-structured Python and SQL to acquire, clean, and explore data
- Apply the correct statistical reasoning to validate findings rather than just eyeballing charts
- Build, evaluate, and tune both classical ML models and deep learning models, and know when to reach for which
- Design and ship an LLM-powered application — including retrieval, memory, and multi-step reasoning — rather than just calling an API
- Build and coordinate AI agents that use tools, plan, and act autonomously within guardrails
- Evaluate, monitor, and safely deploy AI systems in a way that would hold up in a real engineering team
- Speak to CS fundamentals confidently in a technical interview, not just in an applied-AI context

The seven projects above serve as the concrete evidence of that: a portfolio spanning classical ML, deep learning, and applied LLM/agent engineering, each shipped and documented rather than left as a notebook.
