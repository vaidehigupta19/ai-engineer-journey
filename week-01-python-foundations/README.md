# Week 1 — Python Foundations

Part of my [AI Engineer Roadmap](#) — 46 weeks, building toward a job-ready AI/Data Science skill set.

**Duration:** Day 1–7 | **Phase:** Phase 1 – Foundations | **Focus:** Core Python

## 🎯 Goal for the week
Get comfortable with Python basics: syntax, data types, control flow, data structures, functions, and error handling — enough to write a small working program from scratch.

## 📅 Day-by-day log

### Day 1 — Setup + First Code
- Installed Python 3, VS Code (+ Python extension), and Jupyter Notebook
- Wrote my first script (`print("Hello World")`)
- Learned variables and core data types: `int`, `float`, `string`, `boolean`

### Day 2 — Strings + Numbers
- String methods: `upper()`, `lower()`, `strip()`, `split()`, `replace()`, f-strings
- Number operations: `+ - * / // %`
- Type conversion: `int()`, `float()`, `str()`
- **Practice:** program that takes name + age and prints a greeting

### Day 3 — Conditionals + Loops
- `if` / `elif` / `else`
- Comparison (`== != > < >= <=`) and logical (`and`, `or`, `not`) operators
- `for` and `while` loops, `range()`
- **Practice:** number guessing game

### Day 4 — Lists + Tuples + Dictionaries
- Lists: create, `append`, `remove`, `sort`, slicing, list comprehension
- Tuples: immutability, when to use them over lists
- Dictionaries: key-value pairs, `get()`, `keys()`, `values()`, `items()`
- **Practice:** contact book using a dictionary

### Day 5 — Functions + Error Handling
- Defining functions with `def`, parameters, return values
- Default parameters, `*args`, `**kwargs`
- `try` / `except` / `finally` for error handling
- **Practice:** calculator function that handles division by zero

### Day 6–7 — Weekend Project
- Solved 5 beginner problems on HackerRank
- Built a mini project: **[To-Do List App / Quiz Game / Tip Calculator]** *(pick whichever you built)*
- Pushed code to GitHub

## 🧠 Key takeaways
Functions and error handling were the shakiest part of the week — *args/**kwargs and knowing when to use try/except/finally vs. just checking conditions first took a few passes to actually stick, not just recognize. Going into Week 2, I want to redo a couple of function exercises from memory (no notes) before moving on — that's usually where "I understood the video" turns into "I can actually write this.

## ✅ Checkpoint
By the end of this week I could write a Python program using variables, loops, conditionals, lists, dictionaries, and functions.
